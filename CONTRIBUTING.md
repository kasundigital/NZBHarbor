# Contributing to NZBHarbor

Thanks for helping improve NZBHarbor. Please open an issue for bugs or compatibility gaps and include the NZBHarbor version, platform, Docker/Compose version, relevant sanitized logs, and whether the issue is download, post-processing, or Servarr integration related.

Never include Usenet usernames, passwords, API keys, or copyrighted NZB payloads in public issues.
