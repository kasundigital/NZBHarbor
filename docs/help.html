NZBHARBOR GUIDE

Setup, integration & troubleshooting

Everything needed for the first Docker release in one place.

1. Install with Docker

git clone https://github.com/kasundigital/NZBHarbor.git
cd NZBHarbor
docker compose up -d --build

Open http://SERVER-IP:6789. The first run generates an API key in config/config.json.

cat config/config.json

Enter that key in the web UI. Go to Servers, add your Usenet provider and use Test before saving. Use the hostname, port and TLS values supplied by the provider.

Logs and updates

docker logs -f nzbharbor

git pull
docker compose up -d --build
Back up the config directory and do not publish it. It contains your API key and Usenet credentials.

2. Connect Sonarr & Radarr

Choose SABnzbd as the download client. NZBHarbor exposes a SAB-compatible API so Servarr can submit jobs and poll queue/history.

Name: NZBHarbor
Host: nzbharbor
Port: 6789
SSL: No
API Key: YOUR_NZBHARBOR_KEY
Category (Sonarr): tv
Category (Radarr): movies

When apps run in different Compose projects, attach them to a shared Docker network or use a reachable server address. Inside a Sonarr container, localhost means Sonarr itself, not NZBHarbor.

Paths

Give all media containers a consistent shared data mount. For example, mount the same host directory as /data in NZBHarbor, Sonarr and Radarr. Consistent paths avoid most completed-download import failures.

3. Troubleshooting

Is NZBHarbor alive?

docker compose ps
curl http://127.0.0.1:6789/api/v1/health
docker logs --tail=200 nzbharbor

Provider test fails

Verify NNTP hostname, TLS/port, username/password, account status, DNS and outbound firewall. Secure NNTP commonly uses 563, but provider settings vary.

Missing articles

Add a fill provider with a higher numeric priority. NZBHarbor tries enabled providers from lowest priority number upward.

Sonarr/Radarr test fails

Verify container networking and API key. Watch docker logs -f nzbharbor while pressing Test. If no request reaches NZBHarbor, the problem is network/host configuration.

Download completes but import fails

This is normally a filesystem-path or permission problem. Confirm both apps can see the completed folder at compatible paths and that Sonarr/Radarr can read the files.

PAR2/RAR error

The Docker runtime includes par2 and unar. A PAR repair still fails if insufficient recovery blocks exist. v0.1 archive handling is intentionally basic.

Wrong API key

grep api_key config/config.json

If the browser cached an old key, remove nzbharbor_api_key from browser local storage and reload.

Port already used

Change only the host side in Compose, e.g. 6790:6789. Docker-network clients still use internal port 6789.
