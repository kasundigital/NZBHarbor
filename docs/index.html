Bring your Usenet downloads into a calmer harbor.

NZBHarbor is a modern self-hosted NZB downloader built around a clear web UI, provider fallback, useful failures, and a SABnzbd-compatible API for Sonarr and Radarr.

Install with DockerConnect Servarr
Docker first

One container, persistent config/download volumes, health checks, and automated multi-arch release tooling.

Servarr friendly

Select SABnzbd in Sonarr/Radarr and point it at NZBHarbor. Queue, history, categories and completion paths are exposed through the compatibility API.

Provider fallback

Configure primary and fill Usenet servers with priorities so missing articles can be attempted against another provider.

Inspect failures

Failed download and post-processing states stay visible in History instead of disappearing into an opaque workflow.

Repair & extract

The Docker runtime includes PAR2 and unar for the first post-processing implementation.

Portable core

The backend is Go, giving the project a straightforward path to later Linux, Windows and macOS builds.

Early, working, and intentionally transparent.

v0.1 is the foundation, not a claim of feature parity with mature downloaders. The roadmap prioritizes persistent NNTP connection pools, deeper integrity checks, richer post-processing and broader platform packaging.
