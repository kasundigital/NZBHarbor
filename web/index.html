Quick setup

  1. Add and test a Usenet server under Servers.
  2. Upload a small NZB and confirm it reaches Completed.
  3. In Sonarr/Radarr select SABnzbd, host nzbharbor, port 6789, and enter this app's API key.
  4. Use category tv for Sonarr and movies for Radarr.

Troubleshooting

Downloads fail immediately

Check provider hostname, TLS port, credentials, and Docker DNS. Run docker logs -f nzbharbor.

Sonarr/Radarr test fails

If the apps share a Docker network, use nzbharbor as host. localhost inside the Sonarr/Radarr container points to that container, not NZBHarbor.

Import fails after completion

Make sure Sonarr/Radarr and NZBHarbor see the same completed download path. A shared /data mount is the simplest layout.

Missing articles

Add a fill provider with a higher priority number. NZBHarbor tries enabled providers in priority order.

PAR/RAR failure

The Docker image includes par2 and unar. Post-processing errors appear in History.
